# CS336 Assignments

## 项目简介

本仓库包含 CS336 课程作业的实现，覆盖语言模型开发的主要流程，包括预训练模型构建、数据清洗与去重，以及模型监督微调和强化学习对齐。

主要内容包括：

* **Assignment 1：从零构建语言模型**
  实现 BPE 分词器、Transformer 模型、AdamW 优化器、训练流程及文本生成。

* **Assignment 4：语言模型数据过滤与去重**
  实现 Common Crawl 文本提取、语言与质量过滤、隐私信息处理、精确去重和 MinHash 模糊去重。

* **Assignment 5：数学推理对齐与强化学习**
  基于 Qwen2.5-Math-1.5B 实现 Zero-shot 评测、SFT、训练数据过滤、逐 token 损失归一化及 GRPO 训练。

本项目完整展示了从原始语料处理、语言模型训练到推理能力对齐的基本技术流程。
