# FastText 文本质量分类实验记录


##  数据来源
正样本来自英文 Wikipedia。huggingface下载，经过脱敏、质量过滤和格式清理。

负样本来自 Common Crawl 的 WARC 文件。先从网页 HTML 中抽取纯文本，并经过脱敏和格式清理后，作为低质量文本样本。


##  数据规模
最终使用的数据集规模如下：

| 数据类型 | 样本数 |
|---------|--------|
| 正样本 | 18,791 |
| 负样本 | 18,791 |
| 总样本数 | 37,582 |

课程给出Common Crawl 的 WARC 文件经过筛选后仅有18,791 个样本，故正样本也设置为18,791 个。
数据集被划分为训练集和验证集：

| 数据集 | 样本数 |
|--------|--------|
| 训练集 | 33,824 |
| 验证集 | 3,758 |

## 训练结果
fastText 训练过程中共读取约 1900 万个词，词表大小为 267,404，标签数量为 2。

训练结束后，模型在验证集上的结果为：

| 指标 | 数值 |
|------|------|
| Precision | 0.9965 |
| Recall | 0.9965 |

## 结果分析
模型在验证集上取得了较高的 Precision 和 Recall，说明它能够很好地区分 Wikipedia 文本和 Common Crawl 网页文本。

不过，该结果也可能受到数据来源差异的影响。Wikipedia 文本通常更规范，而 Common Crawl 网页文本可能包含更多网页噪声。因此，模型学到的不一定完全是通用的文本质量，也可能包含了不同数据来源之间的特征差异。
