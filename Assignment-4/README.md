# CS336 Assignment 4 — 语言模型数据过滤与去重

## 项目简介

实现了一套面向语言模型预训练数据的 Common Crawl 数据清洗流程，将原始网页数据经过文本提取、内容过滤、隐私信息处理和数据去重，转换为质量更高的文本语料。

实现内容包括三大模块：

* **文本过滤**：从 WARC/WET 数据中提取纯文本，并使用 fastText 进行英文识别；实现 Gopher 质量过滤规则，以及 NSFW 和 Toxic Speech 内容检测。
* **隐私与质量处理**：使用正则表达式识别并过滤 Email、电话号码和 IPv4 地址；同时使用 Wikipedia 和 Common Crawl 数据训练 fastText 文本质量分类器，对网页文本进行进一步质量筛选。
* **数据去重**：实现精确行级去重，以及基于 word n-gram、MinHash、LSH 和 Jaccard Similarity 的文档级模糊去重。

---

## 实验分析

### 1. FastText 文本质量分类器

使用英文 Wikipedia 文本作为正样本，Common Crawl 网页文本作为负样本。两类数据均经过脱敏和格式清理，其中 Wikipedia 数据额外经过基础质量过滤。

筛选后的 Common Crawl 数据共有 18,791 个样本，从 Wikipedia 中同样选取 18,791 个样本，构建平衡的二分类数据集。

| 数据类型 |    样本数 |
| ---- | -----: |
| 正样本  | 18,791 |
| 负样本  | 18,791 |
| 总样本数 | 37,582 |

数据集进一步划分为训练集和验证集：

| 数据集 |    样本数 |
| --- | -----: |
| 训练集 | 33,824 |
| 验证集 |  3,758 |

fastText 训练过程中共读取约 1,900 万个词，最终词表大小为 267,404，分类标签数量为 2。

验证集结果如下：

| 指标        |     数值 |
| --------- | -----: |
| Precision | 0.9965 |
| Recall    | 0.9965 |

**分析**：

* 分类器在当前验证集上取得了较高的 Precision 和 Recall，能够较好地区分 Wikipedia 文本与 Common Crawl 网页文本。
* 但这一结果可能受到数据来源差异的影响。Wikipedia 文本通常结构规范、语言完整，而 Common Crawl 中包含更多网页模板和噪声，因此分类器可能同时学习到了部分数据来源特征，而不完全是通用的文本质量特征。

### 2. Common Crawl 数据过滤

对 19,637 个原始 WET 文档依次进行英文识别、Gopher 质量过滤、NSFW 检测、Toxic Speech 检测、质量分类、精确行级去重和 MinHash 模糊去重。

| 阶段      |   剩余文档 | 相对上一阶段保留率 | 相对原始数据保留率 |
| ------- | -----: | --------: | --------: |
| 原始 WET  | 19,637 |      100% |      100% |
| English |  4,012 |    20.43% |    20.43% |
| Gopher  |  3,483 |    86.81% |    17.74% |
| NSFW    |  3,480 |    99.91% |    17.72% |
| Toxic   |  3,477 |    99.91% |    17.71% |
| Quality |    533 |    15.33% |     2.71% |
| MinHash |    533 |      100% |     2.71% |

**分析**：

* 原始 19,637 个文档中仅有 4,012 个通过英文语言识别，说明原始数据中包含大量非英文或语言识别置信度不足的文本。
* Gopher 规则进一步删除了约 13% 的英文文档，主要过滤长度异常、单词结构异常以及符号比例过高的文本。
* NSFW 和 Toxic Speech 过滤分别只删除了少量文档，说明在当前数据样本和过滤阈值下，高置信度有害内容所占比例较低。
* Quality Classifier 是最严格的过滤阶段。3,477 个文档中仅有 533 个被判定为高质量文本，说明经过基础规则过滤后，仍有大量网页文本与 Wikipedia 风格的高质量文本存在明显差异。
* Exact Line Dedup 对 76,821 行文本进行全局精确去重，最终保留 44,743 行，删除 32,078 行重复内容，行级保留率为 58.24%。
* MinHash + LSH 模糊去重阶段输入 533 个文档，最终仍保留全部 533 个文档。可能是因为前面的语言过滤、Gopher 规则、Quality Classifier 和 Exact Line Dedup 已经进行了较严格的数据清洗，同时最终数据集只有 533 个文档，规模相对较小，minhash 值的碰撞概率较低。
* 最终保留 533 个文档，占原始数据的 2.71%，说明从原始网页数据构建语言模型训练语料需要经过较严格的数据筛选。
